# 取り合わせ
自社EC「KEICHIKU TARUMI Gallery Shop」の複数商品購入を促進するために制作しているWebアプリ。

## Demo
URL：[https://combination-toriawase.netlify.app](https://combination-toriawase.netlify.app)

## 概要
Shopify Storefront APIから商品情報を取得し、
①花器・一輪挿し　
②敷板　
③盆栽・蘭・山野草
の各カテゴリーから商品を選択して、取り合わせ結果と合計金額を確認できる。
商品を単体で見るだけでなく、複数の商品を組み合わせながら検討できる購入体験を提供することを目的とする。

## 背景
直近約1年の注文における１注文あたりの平均購入点数は1.48点で、
1点のみを購入する注文が全体の約60％を占めていた。
一方、花器と敷板を同時購入した注文の平均注文額は単一カテゴリーのみの注文と比較して約1.8倍だった。
この結果をもとに「商品を組み合わせて検討できる体験を提供することで、複数商品の購入につなげられるのではないか」
という仮説を立てた。
しかし本店サイトでは商品がカテゴリーごとの表示となっており、
複数カテゴリーの商品を同時に比較・選択する体験が十分に提供できていなかった。

そこで花器・敷板・植物を組み合わせながら商品を選ぶことができる
「取り合わせシミュレーター」の企画・制作を開始。

## 目標
導入後のKPIを1注文あたりの平均購入点数を1.48点から2.0点と設定。
※KPI達成については今後本店ECへの導入後に検証予定。

## 課題
・1点のみを購入する注文が全体の60％を占めている
・複数カテゴリーの商品を組み合わせて検討できる導線がない
・複数購入につながる購入判断材料が不足している

## 実装方法
・Shopify Storefront APIを使い、商品情報を取得
・カテゴリーごとに商品を選択できるUIを作成
・商品の組み合わせ結果を表示

## 使用技術
・HTML
・CSS
・JavaScript
・Shopify Storefront API（GraphQL）

## 技術選定
以下の3点から本店サイトは変更せず、別サイトとしてShopify Storefront APIを用いて構築。
運用面：テーマエディタが使えなくなるため、他の運営スタッフが文言・画像を追加ができなくなってしまうため
アプリ：テーマ上で運用しているShopify アプリが動作しなくなるため
リスク：すでに運用中である本店サイトを検証がない状態で置き換えることになってしまうため

## 実装した機能
・商品情報の取得（Shopify Storefront API）
・カテゴリー別の商品一覧表示
・カテゴリーごとの商品選択機能
・選択結果の組み合わせ表示
・商品価格表示
・レスポンシブ対応
・スクロール位置保持
・売り切れ商品の表示制限（文言追加と価格の非表示）
・選択商品の合計金額表示
・固定配置ヘッダーの実装（スマホ表示のみ）

## 今後の改善予定
・本店サイトとカート連携
	→選択した商品をそのまま購入フローにつなげ、購入までの導線を作成する。
・住宅空間をイメージできるようなビジュアルをAIで生成し、選択商品配置イメージの提案ができる機能
	→現在は商品の組み合わせ確認まで実装しているが、より購入後の空間イメージを持っていただくために、今後は視覚的な提案機能へ発展させていく。
