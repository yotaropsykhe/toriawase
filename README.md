#取り合わせ
自社EC「KEICHIKU TARUMI Gallery Shop」の商品をカテゴリー別に選択し、取り合わせをシミュレーションできるWebアプリ。

##Demo
公開URL：[https://combination-toriawase.netlify.app](https://combination-toriawase.netlify.app)

##概要
Shopify Storefront APIから商品情報を取得し、各カテゴリー（①花器・一輪挿し　②敷板　③盆栽・蘭・山野草）から商品を選択し、取り合わせ結果を表示する。

##背景
ECサイト運営に関わる中で、既存顧客と新規顧客の間に購入体験の違いがあることに気づいた。
既存顧客である「花の教室」の生徒さんはアトリエで実際の商品を確認し、空間に置いたイメージを持つことができる。
一方で新規顧客はECサイト上の商品画像や説明のみで購入の判断をする必要があり、
商品を暮らしの中で使用するイメージを持ちづらいという課題があった。

そこで購入前の商品選びをサポートするため、
複数の商品を組み合わせながら確認できるWebアプリを制作した。

##課題
・本店サイトでは組み合わせた際のイメージがわかりづらい
・新規顧客に対しての購入判断材料が少なく、既存顧客に比べて複数購入に繋がりにく

##実装方法
・Shopify Storefront APIを使い、商品情報を取得
・カテゴリーごとに商品を選択できるUIを作成
・商品の組み合わせ結果を表示


##使用技術
・HTML
・CSS
・JavaScript
・Shopify Storefront API（GraphQL）

##実装した機能
・商品情報の取得（Shopify Storefront API）
・カテゴリー別の商品一覧表示
・カテゴリーごとの商品選択機能
・選択結果の組み合わせ表示
・商品価格表示
・レスポンシブ対応
・スクロール位置保持
