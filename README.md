# toriawase
Shopify Storefront APIで商品を取得して表示

現状：
既存顧客は花の教室の生徒さんが大半で、別カテゴリー商品を複数点購入していただける傾向にある。
一方非生徒さんの新規顧客は、一点のみの購入で止まっていた。

対策：
新規顧客の購入障壁を下げるともに、複数購入に繋がるように提案サイトを本店外に作成する。

技術選定：
以下４点の懸念からShopify Storefront APIを使い、サブドメインに別サイトを立てる。
→①運営メンバーもShopify　テーマエディタを使いコンテンツ追加を行っているため
 ②テーマ差し込み型のアプリが使用できなくなるため
 ③既存URLが変更となり、検索流入を一時的に失ってしまうため
 ④本店サイトを崩してしまうリスクがあるため

使用技術：
・HTML
・CSS
・JavaScript
・Shopify Storefront API（GraphQL）
